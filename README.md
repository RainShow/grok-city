# Grok City

夜班仪表盘。底栏和城里走动的人读 `public/fleet.json`。`source` 为 `live` 时抬头显示实时更新时间，超过两小时显示数据已过期；拉不到文件时用内嵌样例。稿件流水线仍是浏览器里的模拟。点开一张卡可以复制 id，或用 `grokbot://` 打开对话。城中心是借腹南瓜城，广场边上立着七道门：时间、因果、重力、知觉、尺度、形体、路径。

审批停在浏览器里。批准、编辑、拒绝都不会发到 X、抖音或任何服务器。

## 本地看

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 生产包，产物在 dist/
```

`dist/` 用了相对路径，可以整目录放到站点的子路径（例如 `/city/`）。不要覆盖站点根目录。说明写在 `dist/CITY.txt`。

可选：`?at=21` 从晚上九点开班。

## 点哪里

1. 打开 `/`。抬头是「Grok City · 夜班」，在线计数跟花名册一致。中间是夜城，底下是可滚动的 bot 卡，夜班核心排在前面。
2. 看 proto 把稿子沿街送去钩子房。`city.log` 署名是真实 bot 名。右侧浏览 / 关注 / 分享会自己走。
3. 左侧出现「需要你」时，选一道门（时间 / 因果 / 重力 / 知觉 / 尺度 / 形体 / 路径），或批准借腹南瓜城那句「天亮前谁也别走」。四十秒没人应，城会自己选「时间」。审批卡署名是 pumpkin 或 Grok。
4. 稿子走到 Grok 那一关，点批准、编辑或拒绝。这一关不会自己放行。
5. 任务板跟着变。底栏状态来自 fleet.json 样例。点一张卡，主按钮「打开对话」走深链，id 可以复制。页脚写着「数据：fleet.json（样例）」。post 写的是「模拟发出」。
6. 点底下「汇总」，或等六条额度满 / 点「收班」，看这一夜的浏览、关注、分享。

头顶 `1x / 2x / 4x` 可以加快。
